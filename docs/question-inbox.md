# Question inbox

The weekly question routines read this file. Add the game's **My weak spots** list, **Report a problem** list, or struggle-log topics under "Waiting", each with the date. The writer routine moves what it used to "Done" with the pull request number.

Line types the study buddy adds for you: "<date> STRUGGLE: <topic>, 5 questions. What confused me: ..." (a topic you asked about) and "<date> WEAK: <topic> (<counts>); ..." (the top topics from your weak-spots list). The writer does STRUGGLE lines first, then WEAK lines, then other weak-spot topics.

How to add by hand (no Terminal): in https://claude.ai/code, pick this repository and say 'Add this to docs/question-inbox.md under "Waiting", with today's date, through a small pull request, and merge it yourself once the automatic check passes: <paste>'.
