# Elissa's study guides (USMLE Step 1 and NBME)

Study material, not patient care guidance. Each guide follows Elissa's own course notes (El-Husseiny, Osmosis and others), cited by page. Every fact also cites a source that was opened (StatPearls, MSD Manual, guidelines). Where newer guidance differs from the notes, the guide adds a marked **Recent change** note. Each guide is checked by an accuracy auditor before use.

## How to use a guide
1. Read "In one line" and "Core mechanism" without notes.
2. Cover the compare table and rebuild it from memory.
3. Do the vignette and practice questions before reading the answers.
4. Redo only the practice questions after 1, 3 and 7 days (spaced retrieval).
